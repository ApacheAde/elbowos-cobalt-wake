# Cobalt Wake

Full-colour Python 3 neon light-cycle arcade for [ElbowOS](https://x.com/ElbowOS).

Ride a cyan ribbon across a cobalt grid.
Magenta RIX and gold SOL lay rival wakes.
Mint orbs pay. Crash a foe for a CUT. WASD / arrows steer.

## Play

```
pip install -r requirements.txt
python3 cobalt_wake.py --play
```

## Record a 9:16 reel

```
python3 cobalt_wake.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
